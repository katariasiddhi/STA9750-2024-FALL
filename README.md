Welcome to the official repository for **STA9750 - Fall 2024 coursework and projects.**
This repository contains code, datasets, reports, and analysis completed as part of the curriculum for the STA 9750 class at Baruch College (Zicklin School of Business).

Course Overview

STA 9750 focuses on advanced statistical methods, data analysis, and business applications.
Topics covered may include:
- Exploratory Data Analysis (EDA)
- Regression Analysis
- Predictive Modeling
- Statistical Inference
- Machine Learning Basics
- Business Decision Making with Data
